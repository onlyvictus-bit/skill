# Evidence independence and synthesis

Decision claim: the isolated optional adapter can expose actual local Semantica mechanisms without replacing existing authorities. Origins: (A) pinned target repository source/history/contracts and baseline tests, (B) pinned upstream source/package metadata, (C) real installed worker and actual CAS/ledger run observations. Official docs and README claims sharing upstream origin count with B, not as additional votes. Both agent readings of B are one origin family; baseline and regression tests share A assumptions. Runtime execution adds behavioral evidence C, not semantic validity.

Contradictions resolved: README/API capability names did not prove bounded ACL-aware traversal, deterministic embeddings or real validation. Direct source showed auto-created endpoints, post-traversal limits, fallback vectors and placeholder ontology route. The bridge deliberately validates and constrains these mechanisms, then observed the real runtime. Agent completion claims were challenged; identified faults were reproduced as failures and fixed before final checks. Runtime final reviewer was unavailable in the last pass; no passing independent witness is fabricated.

Agreement strength is sufficient for local structural/transport readiness only. Source truth and embedding quality are unsupported without independent semantic ground truth. The fixture comparison shares synthetic definitions and cannot establish real coding success. Direct inspection matched graph source recall with substantially lower startup cost in tiny fixtures; no promotion of graph default is justified. Weakest link and falsifier are explicit in plan-review.md.
